§ 01

What PathFinder does

Given a graph of zones and a shared reservation table, it routes N drones from start to end — one at a time — reserving each path so the next drone avoids conflicts.

GraphNetwork
+
ReservationTable
→
PathFinder
→
dict[drone_id → path]
Key idea: each drone's path is found with A* (turn cost + congestion), then immediately reserved. The next drone sees those reservations as blocked capacity — so it naturally routes around congestion.
Inputs per drone call

start — zone name (e.g. "overflow_hell1")
end — destination zone name
ReservationTable — shared state, updated after each drone

Output per drone

A list[PathStep] — ordered list of (zone_or_link, turn) tuples. The simulation reads this to move the drone turn by turn.

# PathStep is either a zone name or a link crossing
PathStep = tuple[str, int]

# Examples:
("overflow_hell1", 0)   # zone step — drone is at this zone at turn 0
("conv_r1-conv_r2", 3)  # link step — crossing a restricted link at turn 3
("conv_r2", 4)           # zone step — arrived after the restricted crossing
§ 02

Types & constants

Three small definitions that shape the whole file.

PathStep = tuple[str, int]
# ("zone_name", turn) OR ("src-dst", turn) for restricted link crossing

HeapItem = tuple[int, str, int, list[PathStep]]
# (score, current_zone, current_turn, path_so_far)

ZONE_PRIO: dict[str, int] = {
    "priority": 0,   # explored first — priority zones are fastest lanes
    "normal": 1,     # explored second
    "restricted": 2, # explored last — 2-turn cost makes them unattractive
}
Why ZONE_PRIO? _neighbors() sorts candidates by this before pushing them to the heap. Priority zones get explored earlier in the search — a small tiebreaker that steers drones toward faster lanes when turn costs are equal.
The "-" convention in PathStep

When a step's zone string contains "-" (like "A-B"), it's a link crossing, not a zone arrival. This single character is used everywhere: in _reserve to dispatch to the right reservation method, and in _reserve_zone_step to skip redundant link reservation.

§ 03

_mark_reachable

A DFS that floods backward from the end zone, marking every zone that can possibly reach it. Runs once per assign_all_paths call.

def _mark_reachable(self, end: str) -> None:
    self.can_reach.clear()
    stack = [end]

    while stack:
        zone = stack.pop()
        if zone in self.can_reach:
            continue

        self.can_reach.add(zone)          # mark as reachable
        for neighbor in self.graph.get_neighbor(zone):
            stack.append(neighbor.name)   # explore its neighbors
Why backward? The graph edges point forward (A→B). Flooding backward from end marks every zone that has a path leading to it. Dead ends that can't reach end are never marked — so _neighbors() skips them entirely, pruning useless branches before the heap even sees them.
§ 04

_neighbors

Filters and sorts the candidates for the next move. Only zones in can_reach are returned, sorted by ZONE_PRIO.

def _neighbors(self, zone: str) -> list[Hub]:
    result: list[Hub] = []
    for hub in self.graph.get_neighbor(zone):
        if hub.name in self.can_reach:   # skip dead ends
            result.append(hub)

    result.sort(key=lambda hub: ZONE_PRIO.get(hub.zone, 1))
    return result
Sort order

priority (0) → normal (1) → restricted (2). When two paths have equal turn cost so far, the heap will explore priority zones first — they're more likely to be fast lanes.

Unknown zone type

.get(hub.zone, 1) defaults unknown types to 1 (same as normal). Safe fallback — unknown zones are treated as average.

§ 05

_zone_free & _link_free

Two capacity checks. Both delegate to the ReservationTable; they just know where to look up the capacity limit.

def _zone_free(self, zone: str, turn: int, start: str, end: str) -> bool:
    if zone == start or zone == end:
        return True            # start/end are always free (infinite capacity)
    hub = self.graph.hubs[zone]
    return self.table.is_zone_available(zone, turn, hub.max_drones)

def _link_free(self, src: str, dst: str, turn: int) -> bool:
    conn = self.graph.get_connection(src, dst)
    cap = conn.max_link_capacity if conn else 1  # default cap=1 if unknown
    return self.table.is_link_available(src, dst, turn, cap)
start and end are exempt. Multiple drones can queue at start (waiting their turn) and pile up at end (they've arrived). Only intermediate zones have capacity limits.
§ 06

_can_move

The core guard before any move. Two branches — one for restricted zones (2-turn crossing), one for everything else (1-turn move).

def _can_move(self, src, dst, turn, start, end) -> bool:
    if self.graph.hubs[dst].zone == "restricted":
        link_ok = self._link_free(src, dst, turn + 1) and self._link_free(src, dst, turn + 2)
        return link_ok and self._zone_free(dst, turn + 2, start, end)

    return self._link_free(src, dst, turn + 1) and self._zone_free(dst, turn + 1, start, end)
Why check link at t+1 AND t+2? A restricted crossing occupies the link for 2 turns — the drone is "in transit" across it. Another drone can't use that link until both turns clear.
§ 07

_move_steps

Returns the list of PathStep entries to append to the path when moving from src to dst. One entry for normal moves, two for restricted crossings.

def _move_steps(self, src: str, dst: str, turn: int) -> list[PathStep]:
    if self.graph.hubs[dst].zone == "restricted":
        return [(f"{src}-{dst}", turn + 1), (dst, turn + 2)]
    return [(dst, turn + 1)]

The "src-dst" string with "-" is detected later by _reserve to decide which reservation method to call. It's also detected in _reserve_zone_step to skip double-reserving the incoming link.
§ 08

find_path

The main search loop. Pops the best state from the heap, returns when it reaches end, otherwise expands neighbors and optionally waits.

def find_path(self, start: str, end: str) -> list[PathStep]:
    if not self.can_reach:
        self._mark_reachable(end)
    if start not in self.can_reach:
        return []

    max_turn = self._max_turn()
    heap: list[HeapItem] = [(0, start, 0, [(start, 0)])]
    best_score: dict[tuple[str, int], int] = {}

    while heap:
        score, zone, turn, path = heapq.heappop(heap)

        if zone == end:
            return path         # done — path is complete

        state = (zone, turn)
        if state in best_score and best_score[state] <= score:
            continue            # already found a better path to this state
        best_score[state] = score

        visited = self._path_zones(path)
        for neighbor in self._neighbors(zone):
            dst = neighbor.name
            if dst in visited and dst != end:
                continue        # no revisiting zones (except end)
            if not self._can_move(zone, dst, turn, start, end):
                continue        # capacity blocked

            extra = self._move_steps(zone, dst, turn)
            next_turn = extra[-1][1]
            next_score = next_turn * 100 + self._congestion(zone, dst)
            heapq.heappush(heap, (next_score, dst, next_turn, path + extra))

        if turn + 1 <= max_turn:
            self._push_wait(heap, score, zone, turn, path, start, end)

§ 09

The heap entry

Each entry in the min-heap is a 4-tuple. Python's heapq sorts by the first element, then second, etc. — so score is the primary sort key.

score = turn × 100 + congestion. Multiplying turn by 100 makes turn cost dominate. Congestion (how many drones already used this zone/link) is a small tiebreaker that steers drones away from crowded paths when turn costs are equal.
Why carry the full path in the heap?

No reconstruction step needed. When you pop the goal state, path is already the complete answer. Trade-off: high memory usage if many states are explored, but keeps the code simple and correct.

§ 10

best_score pruning

Prevents re-expanding a state (zone, turn) if we already found a cheaper way to reach it.

    continue   # already cheaper or equal — skip this expansion

Note: The key is (zone, turn) — not just zone. Two paths arriving at the same zone but at different turns are different states and are both valid to explore. This is what allows waiting: a drone at B at turn 3 is a different state from the same drone at B at turn 4.
§ 11

Waiting in place

When all neighbors are blocked, a drone can stay put for one turn. This is pushed as a new heap entry with a +100 score penalty — same cost as moving one step.

def _push_wait(self, heap, score, zone, turn, path, start, end):
    if not self._zone_free(zone, turn + 1, start, end):
        return   # zone full at next turn — can't even wait

    heapq.heappush(heap, (score + 100, zone, turn + 1, path + [(zone, turn + 1)]))
_max_turn() — bounding the wait

Waiting is only pushed if turn + 1 ≤ max_turn. _max_turn() computes last reserved turn + (num_hubs × 4) + 10 — generous enough for any real path, tight enough to prevent infinite loops.

§ 12

_reserve

Walks the completed path and dispatches each step to the right reservation method. The "-" check is the router.

def _reserve(self, path: list[PathStep]) -> None:
    for i, (step, turn) in enumerate(path):
        if "-" in step:
            self._reserve_restricted_link(step, turn)
            continue
        self._reserve_zone_step(path, i, step, turn)

§ 13

_reserve_restricted_link

Reserves the link for both turns of the crossing. Also updates link_use — the congestion counter used by future drones.

def _reserve_restricted_link(self, step: str, turn: int) -> None:
    src, dst = step.split("-", 1)
    link = self._link_name(src, dst)

    self.table.reserve_link(src, dst, turn)
    self.table.reserve_link(src, dst, turn + 1)   # second turn of crossing
    self.link_use[link] = self.link_use.get(link, 0) + 1
_link_name canonicalises direction. min(src,dst) + "_" + max(src,dst) means A→B and B→A have the same key. Links are bidirectional in the reservation table.
§ 14

_reserve_zone_step

Reserves the zone itself and its incoming link — unless we came from a restricted link step (which already reserved the link).

def _reserve_zone_step(self, path, index, zone, turn) -> None:
    self.table.reserve_zone(zone, turn)
    self.zone_use[zone] = self.zone_use.get(zone, 0) + 1

    if index == 0:
        return   # start node — no incoming link

    prev_zone, _ = path[index - 1]
    if "-" in prev_zone or prev_zone == zone:
        return   # came from a link step (already reserved) or wait (same zone)

    link = self._link_name(prev_zone, zone)
    self.table.reserve_link(prev_zone, zone, turn)
    self.link_use[link] = self.link_use.get(link, 0) + 1
prev_zone has "-"

Means the drone just crossed a restricted link. That link was already reserved by _reserve_restricted_link for both turns — no double reservation needed.

prev_zone == zone

The drone waited in place. There's no incoming link to reserve — the drone didn't move, it just occupied the same zone one more turn.

This was the fixed bug. The original code looked at path[i-1] incorrectly for link steps and ended up reserving the wrong link. The fix: check if the previous step string contains "-" and skip link reservation entirely in that case.
§ 15

assign_all_paths

The entry point. Calls find_path and _reserve in a loop — one drone at a time. Each drone's reserved path becomes the capacity constraint for the next.

def assign_all_paths(self, start, end, nb_drones) -> dict[int, list[PathStep]]:
    self._mark_reachable(end)
    paths: dict[int, list[PathStep]] = {}

    for drone in range(1, nb_drones + 1):
        path = self.find_path(start, end)
        if not path:
            raise ValueError(f"No path for drone D{drone}")
        self._reserve(path)         # reserve immediately before next drone
        paths[drone] = path

    return paths
This is cooperative routing. No drone knows about others at planning time — but the reservation table acts as shared memory. Drone 2 naturally avoids where drone 1 has been because those slots are already full.
